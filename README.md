# Sentinel-2 Explorer+

**Sentinel-2 Explorer+** is an Earth observation web application designed to make Copernicus Sentinel-2 satellite imagery easier to discover, visualize, compare, and interpret.

🌍 **Live application:** [https://s2explorer.alvinbaloloy.com](https://s2explorer.alvinbaloloy.com)

## About the Project

Satellite imagery supports environmental monitoring, disaster risk assessment, agriculture, coastal management, land-cover analysis, education, and research. However, many users still face technical barriers when accessing and processing Earth observation data.

Sentinel-2 Explorer+ provides a more intuitive interface for exploring Sentinel-2 imagery without requiring users to build complex processing workflows from scratch.

The platform is intended for:

- Local and national government practitioners
- Researchers and students
- Environmental organizations
- Educators and trainers
- GIS and Earth observation professionals
- Communities exploring satellite-based information

## Current Features

Sentinel-2 Explorer+ currently supports:

- Sentinel-2 imagery search by location and date
- Cloud-cover filtering
- Country-based and area-of-interest exploration
- True Color and False Color visualization
- NDVI and water-index visualization
- Rectangle and polygon area selection
- Temporal image comparison
- Vegetation and water condition summaries
- Land-cover and infrastructure-related analysis
- Downloadable satellite-derived outputs
- AI-assisted imagery search and interpretation through SentiMate
- Exploration profiles, missions, and educational features

> Satellite-derived outputs and AI-assisted interpretations should be validated using appropriate reference information, local knowledge, or field observations.

## Project Background

Sentinel-2 Explorer+ builds on more than a decade of experience in Earth observation, GIS, environmental monitoring, and capacity development.

The project is informed by previous scientific and applied geospatial initiatives, including:

- **Mangrove Vegetation Index (MVI)** – a satellite-based index developed specifically to support mangrove mapping
- **MangroveLEAF** – a platform supporting mangrove monitoring, assessment, and restoration planning
- **NBCAP Blue Carbon Ecosystem Explorer** – a geospatial platform developed to improve access to information on Philippine blue-carbon ecosystems
- Earth observation training and capacity-building activities involving government agencies, academic institutions, environmental organizations, and local practitioners

These experiences highlighted the need for tools that are not only technically capable, but also accessible, understandable, and appropriate for real institutional and community applications.

## Responsible Use

Sentinel-2 Explorer+ is intended to support exploration, education, research, planning, and preliminary environmental assessment.

Results generated by the platform should not automatically be treated as official measurements, regulatory determinations, emergency instructions, or substitutes for field validation and expert assessment.

Satellite imagery availability, atmospheric conditions, cloud cover, spatial resolution, temporal resolution, and model limitations may affect the results.

## Data and Services

Sentinel-2 Explorer+ uses Copernicus Sentinel data and related Earth observation services.

Sentinel-2 Explorer+ is an independently developed application. It is not a replacement for the Copernicus Data Space Ecosystem, official government platforms, or authoritative scientific and operational services.
